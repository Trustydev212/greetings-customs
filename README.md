# Greetings & Customs — Phòng luyện tiếng Anh

Trang web luyện phát âm có chấm điểm bằng giọng nói, nối từ và bàn cờ chào hỏi vòng quanh thế giới cho lớp học.

## Live demo

Sau khi bật GitHub Pages, trang sẽ chạy tại:
<https://trustydev212.github.io/greetings-customs/>

## Chạy cục bộ

Mở file `index.html` bằng trình duyệt, hoặc chạy một server tĩnh trong thư mục:

```bash
python -m http.server 8000
# rồi mở http://localhost:8000
```
